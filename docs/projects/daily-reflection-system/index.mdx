## 目的

日々のタスク、開発活動、振り返りを一緒に扱い、その日の行動を見直せるようにします。分かれていた日報 CLI、ターミナル UI、Agent 向けの仕組みを統合します。

## 目指す姿

GitHub の活動を取り込み、予定の作成、タスク管理、振り返り、ログの閲覧・編集を CLI と TUI から行えるシステムを目指します。共通のデータモデルと JSON 契約を使い、Agent のワークフローからも日次ログを扱えるようにします。
