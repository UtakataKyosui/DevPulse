## 目的

日常の疑問から生まれたアイデア、作品、文章、実験を公開し、それぞれのつながりを通じて自分の考えや活動を伝えます。

## 目指す姿

制作物の一覧だけでなく、関連するアイデアをグラフでたどれる個人サイトを目指します。まずはコンセプト、作品、プロフィールと小規模なグラフを公開し、その後にブログや CMS を拡張する計画です。
