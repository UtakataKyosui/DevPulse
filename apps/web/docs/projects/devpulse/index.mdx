## 概要

GitHub Milestones を正本として、個人開発の進捗を一目で確認できるようにするダッシュボードです。サイト全体は Rspress / MDX で静的に配信し、変動する進捗データだけをブラウザで取得します。

<ProjectOverview />

## 目的

個人開発が止まってしまう状況を減らすため、取り組んでいるプロジェクトとその進み具合を公開し、周囲にも見てもらえるようにします。GitHub の Issue と Milestone を使い、進捗を別途報告する負担を抑えます。

## 目指す姿

各プロジェクトが何を目指し、今どこまで進み、次に何をするのかが一目で分かる公開ダッシュボードを目指します。GitHub の活動を定期的に反映し、開発の継続と停滞に気づくきっかけにします。
