## 目的

生活タスクや習慣の見落としを減らし、毎日の「確認 → 行動 → 記録」を少ない操作で続けられるようにします。アプリを開くこと自体が負担にならない生活管理を目指します。

## 目指す姿

常設ディスプレイで今日やることを確認し、スマホで登録や詳細編集を行える生活の掲示板を目指します。予定と実行記録を分けて管理し、未実行や予定変更があっても次の予定につながる仕組みにします。AI による支援は、その基本サイクルを補助する拡張として考えています。
