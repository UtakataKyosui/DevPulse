## 目的

人間と Coding Agent の双方が、GitHub CLI 拡張を一貫した手順で開発・テスト・保守できるようにします。拡張ごとに出力形式やエラー処理を作り直す負担を減らします。

## 目指す姿

Go / Cobra を基盤に、読みやすいテキストと構造化 JSON、明確な終了コード、復旧判断に使えるエラー情報を備えた拡張のテンプレートを目指します。CI、配布、開発規約も含め、新しい拡張を始めるための再利用可能な土台にします。
