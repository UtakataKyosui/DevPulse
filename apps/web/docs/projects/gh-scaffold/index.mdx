## 目的

リポジトリや Organization が変わっても、一定の形式で Issue と Pull Request を作成できるようにします。リポジトリごとにテンプレートを準備する負担を減らします。

## 目指す姿

Markdown テンプレートを内蔵した GitHub CLI 拡張を目指します。既存のリポジトリテンプレートも利用しながら、本文の編集、投稿前の確認、dry-run を提供し、将来は非対話操作や Coding Agent の本文生成ワークフローにも対応する計画です。
